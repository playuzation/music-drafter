# music-drafter

마디 단위로 작곡하고 바로 반복 재생해 보는 웹 작곡 스케치북입니다. 모바일과 PC 브라우저에서 동작하며, 설치나 빌드 없이 정적 파일만으로 GitHub Pages에서 실행됩니다.

## 기능

- **마디 단위 편집**: 현재 마디 반복 재생, 전체 마디 연속 재생(반복 on/off). 재생 중에 고친 내용이 바로 반영됩니다.
- **음 높이**: 스케일의 1~8도. 스케일은 메이저(장조)와 마이너(자연단음계) 중에서 고르며, 으뜸음은 C로 고정입니다. 트랙마다 옥타브(2~6)를 정합니다.
- **길이**: ¼·½·1·2·4박과 점음표(×1.5). 4/4박자 고정입니다.
- **쉼표**: 음표가 없는 구간이 쉼표입니다. `쉼표` 버튼은 커서 위치부터 선택한 길이만큼 비웁니다.
- **이음표(붙임줄)**: 바로 다음에 오는 같은 높이의 음과 끊김 없이 이어서 재생합니다. 마디를 넘어서도 이어집니다.
- **트랙**: 최대 8개. 정현파·삼각파·사각파·톱니파 중 하나를 고르거나 드럼 트랙(킥, 스네어, 클랩, 로우탐, 하이탐, 닫힌햇, 열린햇, 크래시)으로 씁니다.
- **JSON 저장/불러오기**: 곡을 파일로 내려받고, 다시 불러옵니다.
- **WAV 저장**: 전체 마디를 한 번 연주한 소리를 WAV 오디오 파일로 내려받습니다.
- **악보 보기**: 마디의 음표를 트랙별 오선보로 보여 줍니다. 재생 중에는 연주 중인 마디를 따라가며, 세로선이 움직이고 지금 소리 나는 음이 밝게 표시됩니다.

## 사용법

1. 격자를 탭하면 선택한 길이의 음표가 그 자리에 놓입니다. 아래 `1`~`8` 버튼은 커서(파란 선) 위치에 차례로 입력합니다.
2. 음표를 탭하면 선택됩니다. 이 상태에서 길이 버튼을 누르면 길이가 바뀌고, `이음표`·`음표 삭제` 버튼을 쓸 수 있습니다. 드럼 트랙의 음표는 탭하면 지워집니다.
3. 박자 눈금(1 2 3 4)을 탭하면 커서를 옮깁니다.
4. `▶ 현재 마디`로 지금 보고 있는 마디를 반복해서 듣고, `+ 추가`나 `복제`로 마디를 늘린 뒤 `▶ 전체`로 이어서 듣습니다.

참고
- iOS에서 소리가 나지 않으면 무음 스위치를 확인하세요. 지원하는 Safari에서는 무음 모드에서도 소리가 나도록 설정해 두었지만, 버전에 따라 다를 수 있습니다.
- 카카오톡 같은 앱의 내장 브라우저에서는 파일 저장이 막힐 수 있습니다. 이때는 Safari나 Chrome으로 여세요.
- 곡은 브라우저에 자동 저장되지 않습니다. `JSON 저장`으로 보관하세요.
- 악보의 음자리표와 플랫 기호 글꼴(Noto Music)은 Google Fonts에서 불러옵니다.

## GitHub Pages 배포

1. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로 고릅니다.
2. Branch는 `main`, 폴더는 `/ (root)`로 정하고 저장합니다. 작업 브랜치를 그대로 골라도 됩니다.
3. 1~2분 뒤 `https://playuzation.github.io/music-drafter/`에서 열립니다.

로컬에서 실행할 때는 ES 모듈이라 `file://`로는 열리지 않으니, 정적 서버를 띄웁니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

## JSON 형식

```json
{
  "format": "music-drafter",
  "version": 1,
  "bpm": 120,
  "scale": "major",
  "tracks": [
    {
      "type": "sine",
      "octave": 4,
      "measures": [
        [
          { "start": 0, "len": 4, "deg": 1, "tie": false },
          { "start": 8, "len": 8, "deg": 5, "tie": true }
        ]
      ]
    }
  ]
}
```

- 시간 단위는 16분음표(¼박) 1칸이고, 한 마디는 16칸입니다.
- `start`는 마디 안 시작 칸(0~15), `len`은 길이(칸 수), `deg`는 1~8도입니다. 드럼 트랙에서는 1=킥 … 8=크래시입니다. `tie`는 다음 음과의 이음 여부입니다.
- `type`은 `sine`·`triangle`·`square`·`sawtooth`·`drum` 중 하나이고, `scale`은 `major`·`minor` 중 하나입니다.
- 모든 트랙의 마디 수는 같아야 합니다. 쉼표는 따로 적지 않습니다(음표가 없는 칸 = 쉼표).

## 구조

빌드 없이 브라우저의 ES 모듈로 동작합니다. 모듈 의존성은 순환이 없는 트리 형태입니다.

```
index.html, style.css
js/main.js        컨트롤러: 앱 상태, UI 액션 처리, 재생 연결
├─ js/song.js     곡 데이터·편집 연산·이음표 해석·JSON 검증 (순수 로직)
│  └─ js/theory.js  스케일 → 음 높이·주파수·이름
├─ js/audio.js    AudioContext, 미리듣기, 룩어헤드 스텝 시퀀서, 오프라인 렌더링
│  ├─ js/synth.js   파형 톤과 드럼 합성
│  └─ js/wav.js     WAV 파일 인코딩
└─ js/ui.js       DOM 렌더링과 입력 처리
   └─ js/score.js   오선보 SVG 그리기
```
